# しってるっこ 〜こたえを知ってる子が まぎれてる〜

おだいばん👑だけが知っているお題を「はい／いいえ／わからない」の質問で当てる。でも、こたえを知ってる子（しってるっこ🤫）がこっそりまぎれている。当てたあとは犯人さがし！
既存の正体隠しゲームの仕組みを参考にした、ブラウザで遊べるオリジナル作品です。NPC（ふーさん🐻・ミミ🐰・ロボミ🤖・ニャコ😺・ポチ太🐶・コンタ🦊）が どの役でもこなすので、ひとりでも遊べます。

**ふらっとgames　制作 watg**

- 4〜8人（人間1〜8人＋NPC）。iPhone（375px〜）優先のレイアウト、Safari／Chrome
- サーバーなし：静的ファイルだけ（GitHub Pages など）。通信は PeerJS（WebRTC・STUNのみ）で、ホストの端末が進行役（host-authoritative）
- お題は おだいばん・しってるっこ の端末にだけ送り、たんていの端末には正解が出るまで送りません。役わりも本人にだけ
- 部屋コード＋招待URL＋QR、リロード後の入り直し、`?from=portal` で「🏠 ひろばへ」ボタン（ゲーム中は隠す・⋯メニューにも）
- 🎤 音声入力（Web Speech API）：話した質問がそのまま質問に。おだいばんは「はい」と話しても答えられる
- ルールの出典と判断：[RULES_NOTES.md](RULES_NOTES.md)

## NPCの頭脳（brain.js）

- **お題ずかん**：475語 × 133の特ちょう＋語ごとの「関係ることば」。カテゴリから引きつぐ値＋語ごとの上書き＋反対の関係（やわらかい⇔かたい・日本⇔外国 など）から組み立て、矛盾チェックはテストで常に実行。自信がないものは「わからない」(`?`)
- **おだいばんNPC**：質問を読み取り → ずかんの値で はい／いいえ。特ちょうだけで説明できない質問は「関係ることば」で答え、それでも分からなければ わからない（知らないことばに「いいえ」と言わない）。特ちょうどうしで答えが割れるときも わからない。名前の書き方ゆれ（ドッチ／ドッジ、濁点・長音・1文字ちがい）も正解あつかい。自然な質問 約1,350問（`test/natural_*.txt`、`node tools/natcheck.js <file> v`）で 自信のある まちがい 0%（旧版 24〜41%）。お題の名前や同じ意味のことばを含む質問は 🎯正解
- **たんていNPC**：全お題の確率（ベイズ）を持ち、答えのまちがい（人間のおだいばん）も少し見こむ。次の質問は「答えでどれだけ候補が割れるか」（情報量）で選ぶ。確率が十分高ければ答えを言う
- **しってるっこNPC**：ふだんは たんていと同じ質問の選び方。時間が少なくなると、お題に近づく質問をこっそり混ぜる（学習の結果：前半は誘導なし、後半に強め）
- **見やぶり**：各質問の「情報量の期待値」と「お題を知っている人なら得られる量」の差（もれ）を人ごとに集計。正解者のもれ・最大のもれ・推理の速さで投票①②を決める。結果画面で質問ごとの「もれ」バーが見られる
- **レベル**：やさしい／ふつう／かしこい／アストラウルトラ😎。学習済みパラメータと手作りパラメータを混ぜ、弱いほど ゆらぎ・雑な質問が増える。アストラウルトラは学習済みそのまま

### 自己対戦の学習（tools/train.js）

進化戦略（λ=12, μ=4, 20世代 × 240試合, 8スレッド）。学習は380語、評価は使っていない95語。人間っぽいボット（雑な質問・ミス）も混ぜて対戦。

| 評価（未使用95語） | 学習前（手作り） | 学習後 |
|---|---|---|
| しってるっこの勝率（自己対戦） | 6.1% | 53.3% |
| たんていの勝率（自己対戦） | 92.2% | 78.6% |
| 正解までいけた率 | 98.9% | 99.7% |

### 統計（test/sim.js 150、各150試合、未使用のお題だけ）

- 正解率：全レベル 100%（5分・2分とも）、平均 8〜9.5問
- 見やぶり率（たんていNPCの勝ち）vs 手作り／学習済み／人間っぽいしってるっこ：やさしい 97/31/91%、ふつう 99/37/96%、かしこい 98/41/95%、ウルトラ 93/43/90%
- しってるっこNPCの生きのこり（vs ふつう／ウルトラのたんてい）：やさしい 4/7%、ふつう 5/4%、かしこい 12/9%、ウルトラ 63/61%
